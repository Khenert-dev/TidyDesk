# TidyDesk

**A simple Windows file organizer by Khenert-dev.**

Group loose files into folders, review destinations before moving anything, automatically sort future downloads, and undo recent batches. Includes Light and Dark appearance.

## Download

Get the Windows x64 installer from the repository's **Releases** page. Choose the installer asset, not GitHub's automatically generated “Source code” ZIP. No Python installation is needed. This repository distributes the app and public documentation; the application source is private.

The SHA-256 checksum lets you check download integrity. The installer is unsigned; a checksum does not establish publisher identity.

## Start here

1. Install and open TidyDesk from the Start menu.
2. Choose **Add folder** and select your actual Desktop, browser-download, or other inbox folder.
3. Choose **Add and review**, check **Move to**, then choose **Organize**.
4. Enable **Automatically sort new files** if you want future downloads handled automatically.

Files are grouped into subfolders by default. A separate output must be on the same drive. Existing subfolders stay in place; existing files are not overwritten. Read [INSTRUCTIONS.md](INSTRUCTIONS.md) for setup, examples, Undo, and troubleshooting.

## Features

- Documents, images, archives, installers, code/data, ISO disk images, OVA/VM files, and configurable rules.
- Manual review before organizing existing files; automatic sorting is optional.
- Persistent history and content-checked Undo.
- **Settings → Appearance → Theme** for Light or Dark.
